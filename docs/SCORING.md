# Эксперты, оценки и рейтинг

Оценивание начинается после `deadline_at` опубликованного хакатона. Организатор
назначает эксперта на последнюю версию решения команды по конкретному кейсу.
Предыдущие версии остаются в истории команды, но не оцениваются. Один эксперт
получает не более одного назначения на эту сдачу. Эксперт должен иметь активную
роль `expert` и не может быть участником оцениваемой команды.

Назначенный эксперт видит критерии и метаданные решения, а архив скачивает через
защищённый маршрут `/api/v1/submissions/{id}/archive`. Доступ к другой сдаче,
даже той же команды, назначение не открывает. Организатор видит назначения
только своего хакатона. Роль и принадлежность проверяются по БД на каждом запросе.

## API

| Метод и путь | Назначение |
|---|---|
| POST `/api/v1/organizer/hackathons/{id}/assignments` | Назначить эксперта на последнюю сдачу |
| GET `/api/v1/organizer/hackathons/{id}/assignments` | Назначения своего хакатона |
| GET `/api/v1/expert/assignments` | Назначенный пул эксперта |
| GET `/api/v1/expert/assignments/{id}` | Решение и критерии своего назначения |
| PUT `/api/v1/expert/assignments/{id}/scores` | Атомарно заменить баллы по критериям |
| GET `/api/v1/hackathons/{id}/cases/{case_id}/leaderboard` | Публичный рейтинг кейса после дедлайна |

Тело назначения: `{"team_id": 1, "case_id": 1, "expert_id": 4}`. Баллы:

```json
{"scores": [{"criterion_id": 1, "value": 8}, {"criterion_id": 2, "value": 5}]}
```

`PUT` заменяет весь набор баллов эксперта. Можно сохранить часть критериев;
такая оценка пока не участвует в рейтинге. Пустой список очищает оценку.
Повторяющиеся, чужие и выходящие за диапазон критерии отклоняются без изменения
прежнего набора. Поле итогового балла в запросе запрещено.

## Расчёт

Для полной оценки одного эксперта:

```text
normalized_i = (score_i - min_score_i) / (max_score_i - min_score_i)
expert_total = 100 * sum(weight_i * normalized_i) / sum(weight_i)
team_total = mean(expert_total всех экспертов с полной оценкой)
```

Промежуточные вычисления используют `Decimal`. Итог округляется до двух знаков
по `ROUND_HALF_UP` только после усреднения. Например, веса 3 и 1 и баллы
8/10 и 5/5 дают 85.00. Баллы не записываются в таблицу рейтинга: каждый запрос
вычисляет его из актуальных оценок. Поэтому изменение оценки сразу меняет
leaderboard, а пользователь не может записать итог вручную.

Рейтинг отдельный для каждого кейса. В нём только команды с последней сдачей и
хотя бы одной полной оценкой. Сортировка: итог по убыванию, затем ID команды по
возрастанию. Равный отображаемый итог даёт одинаковое место; следующий номер
места пропускается по числу команд выше. Отзыв роли эксперта закрывает доступ к
назначению и исключает его оценки из текущего рейтинга до повторного назначения
роли.
