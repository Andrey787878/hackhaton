# Источник основы

Авторизация, RBAC, ORM, DTO и первые миграции перенесены из репозитория автора:

- https://github.com/Andrey787878/backend-labs
- Ветка `lb3`, включающая авторизацию `lb2`.
- Коммит `5e607efccd350e7566b0825b005b0d6a971fdbe6`.

Адаптации первого этапа:

- API под `/api/v1`, RBAC под `/api/v1/admin`.
- Health endpoint с PostgreSQL, автоматические миграции в Compose.
- Генерация локальных секретов, непубличный порт БД.
- Прямой bcrypt вместо passlib, проверка длины пароля в байтах.
- Refresh с неверной подписью не изменяет сессии по непроверенным claims.
- `user` и `guest` не получают административных разрешений лабораторных сидов.
- Технический пользователь сидов получает случайный неизвестный пароль.
- Специальные символы реквизитов БД корректно кодируются в URL.
- ORM-индексы и уникальные ограничения приведены в соответствие с миграциями.
- Добавлены интеграционные тесты и план предметных модулей.

Миграция сидов адаптирована до первого развёртывания нового проекта.
База лабораторных к этому приложению не подключается.

Этап 2: новая миграция `20260927_0003` добавляет необязательные birthday/display_name,
роли organizer/participant/expert и их разрешения. Регистрация атомарно выдаёт
participant, ответы auth возвращают актуальные роли. Добавлены PATCH собственного
профиля, операторский CLI bootstrap и тесты назначения/отзыва прав.

Этапы 3–4 — новая предметная логика платформы. Из `backend-labs` перенесена только
базовая архитектура авторизации/RBAC; модели хакатонов, команд и их API созданы
в текущем проекте.
