# Фронтенд: веб-интерфейс HackPulse

Клиентская часть платформы онлайн-хакатонов. Это SPA, которое работает только
через REST API `/api/v1` и не обращается к базе данных напрямую. Палитра построена
на оттенках чёрного, синего и красного: синий — основное действие и активная фаза,
красный — дедлайн, ошибки, опасные действия и лидеры рейтинга.

## Стек

| Технология | Зачем |
|---|---|
| React 18 + TypeScript 5 | компонентный UI, строгая типизация DTO бэкенда |
| Vite 8 | dev-сервер с HMR, прокси `/api` → FastAPI, production-сборка |
| React Router 7 | маршруты страниц и защита по ролям |
| CSS с дизайн-токенами | собственная тема без UI-фреймворка, адаптивная вёрстка |
| Inter + JetBrains Mono (@fontsource) | шрифты подключены локально, без CDN |
| Vitest | unit-тесты формулы оценки, часов, ошибок API, валидации |
| nginx (Docker) | раздача сборки и прокси `/api` на контейнер `api` |

HTTP-клиент написан на `fetch` без сторонних библиотек: Bearer-токен,
общий refresh при 401 с блокировкой между вкладками (сервер отзывает все сессии
при повторном использовании старого refresh), разбор ошибок FastAPI/Pydantic
на понятный русский текст. Загрузка архива идёт через `XMLHttpRequest`, потому что
только он отдаёт прогресс отправки.

## Запуск

Вместе со всем проектом (Docker Compose поднимает БД, MinIO, API и `web`):

```bash
python3 scripts/init_env.py
docker compose up --build -d --wait
```

Интерфейс: http://localhost:3000 (порт меняется через `WEB_PORT` в `.env`).
nginx проксирует `/api/*` на `api:8080`, поэтому браузер работает с одним origin
и CORS на сервере не нужен.

Режим разработки (API уже запущен на `localhost:8080`):

```bash
cd frontend
npm ci
npm run dev        # http://localhost:5173, /api проксируется на localhost:8080
npm test           # unit-тесты Vitest
npm run build      # проверка типов и сборка в dist/
```

Другой адрес API для dev-прокси задаётся переменной `API_PROXY_TARGET`,
базовый путь API в браузере — `VITE_API_BASE` (по умолчанию `/api/v1`).

Демоданные для интерфейса (нужны аккаунты `seed-demo` и `.local/demo-accounts.json`,
см. [DEMO.md](DEMO.md)):

```bash
python3 scripts/seed_ui_demo.py
```

Скрипт через HTTP API создаёт три опубликованных хакатона: идущий (приём открыт
3 часа), будущий и завершённый с оценками и рейтингом. Пароли созданных участников
сохраняются только в игнорируемый Git файл `.local/ui-demo.json`.

## Страницы и требования ТЗ

| Маршрут | Роль | Что делает | Требование |
|---|---|---|---|
| `/` | все | опубликованные хакатоны, фильтр по фазе, таймеры | — |
| `/hackathons/:id` | все | сроки, обратный отсчёт по серверному времени, кейсы и критерии, создание команды | FE-01 |
| `/hackathons/:id/leaderboard` | все | рейтинг по кейсам, автообновление каждые 10 с, подсветка изменений | FE-05 |
| `/login`, `/register` | гость | вход, регистрация с проверкой правил пароля | NFR-04/05 |
| `/teams` | участник | мои команды, вступление по invite-коду | BE-02 |
| `/teams/:id` | участник | состав; капитану — переименование, выпуск и отзыв кода; сдача ссылки/архива с прогрессом и серверным временем; история и скачивание | FE-02, FE-03 |
| `/expert`, `/expert/assignments/:id` | эксперт | назначенный пул, форма оценки с диапазонами и весами, предпросмотр итога | FE-04 |
| `/organizer`, `/organizer/hackathons/:id` | организатор | создание и редактирование, кейсы и критерии, публикация, команды и их сдачи, назначение экспертов | BE-03, BE-08 |
| `/notifications` | вошедший | журнал событий, отметка прочтения, счётчик в шапке | BE-12 |
| `/profile` | вошедший | имя и дата рождения, ID для назначения экспертом, активные сессии | — |

Права всегда проверяет сервер; интерфейс лишь скрывает недоступные действия
(например, не-капитан не видит управления командой и формы сдачи).

### Серверное время (FE-01)

`utils/serverClock.ts` запрашивает `GET /api/v1/time` и вычисляет смещение часов
устройства с поправкой на половину времени запроса. Таймер, фаза хакатона и
доступность формы сдачи считаются по серверному времени; при смене фазы страница
перезагружает данные. Если часы устройства расходятся с сервером больше чем на
секунду, таймер это показывает.

### Добавленный маршрут API

После дедлайна публичный `GET /hackathons/{id}/cases` закрыт (материалы доступны
только в период проведения), поэтому наблюдатель не мог узнать, какие рейтинги
открыть. Для страницы итогов добавлен публичный
`GET /api/v1/hackathons/{id}/leaderboard`: рейтинги всех кейсов с названиями,
доступны после дедлайна опубликованного хакатона (до него — 409). Логика
рейтинга переиспользует существующий `ScoringService.leaderboard`; тест —
`tests/test_scoring.py::test_hackathon_leaderboard_lists_every_case`.

## Структура

```text
frontend/
├── Dockerfile               # node: сборка → nginx: раздача
├── nginx.conf               # SPA fallback, прокси /api → api:8080, лимит тела 21 МиБ
├── vite.config.ts           # dev-прокси /api, настройки Vitest
├── index.html, public/favicon.svg
└── src/
    ├── main.tsx             # точка входа: роутер, AuthProvider, стили
    ├── App.tsx              # карта маршрутов и защита по ролям
    ├── api/                 # сервисный слой работы с REST API
    │   ├── client.ts        # fetch: Bearer, refresh rotation, ошибки, upload с прогрессом, download
    │   ├── errors.ts        # ApiError, перевод ответов FastAPI/Pydantic
    │   ├── types.ts         # типы DTO бэкенда
    │   ├── auth.ts          # /auth: вход, регистрация, профиль, сессии
    │   ├── hackathons.ts    # публичные хакатоны, кейсы, рейтинг; кабинет организатора
    │   ├── teams.ts         # команды, invite-коды, сдачи, архивы
    │   ├── scoring.ts       # назначения экспертов и оценки
    │   └── notifications.ts # журнал уведомлений
    ├── auth/
    │   ├── AuthContext.tsx  # текущий пользователь, login/register/logout
    │   ├── RequireAuth.tsx  # защищённый маршрут и проверка роли
    │   └── tokenStorage.ts  # пара JWT, синхронизация между вкладками
    ├── hooks/               # useAsync (загрузка), useInterval (опрос), useServerNow (часы)
    ├── components/          # Layout, Countdown, CriteriaTable, Badges, Feedback, Icon
    ├── pages/               # страницы из таблицы выше
    ├── utils/               # форматирование, формула оценки, серверные часы, валидация, роли, тесты
    └── styles/              # tokens.css (палитра), base.css, components.css, pages.css
```

Поток данных: страница → хук `useAsync` → сервис `api/*.ts` → `client.ts` →
`/api/v1` (Vite-прокси или nginx) → FastAPI → PostgreSQL/MinIO.
